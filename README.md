# 💫 About Me:
I’m a software engineer working mainly in Go, Python/Django and React/TypeScript.
At Qmeter, I’m the sole engineer behind the company’s full product portfolio, and I lead a DevOps engineer and two support engineers. I build queue-management systems, kiosks and digital signage for banks, running across 110 branches.
Outside Qmeter, I build and run my own products: Speedtest.az, NetWatch, maas.az and aze.zip.
Before that, I spent three years at C.H. Robinson in Poland, automating finance reporting with Python, SQL and Power BI.
I work mostly on backend architecture, real-time systems and taking projects from idea to production.
